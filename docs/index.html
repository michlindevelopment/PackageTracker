How to install

  1. Tap Download above.
  2. Open the downloaded file from the Files app — not from the browser's download bar.
  3. Android will ask to allow installing from this source. Allow it.
  4. Open the app and grant the permissions it asks for.
Step 2 matters Installing straight from the browser makes Android block the app's SMS access, so it can't match delivery texts to your parcels. Opening the APK from the Files app avoids that. If SMS is already blocked: App info → ⋮ menu → Allow restricted settings → Permissions → SMS → Allow.
