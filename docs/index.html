How to install

  1. Tap Download above.
  2. Open the downloaded file.
  3. Android will ask whether to allow installing apps from this source. Allow it.
  4. Open the app and grant the permissions it asks for.
If you see a Play Protect warning Android shows a caution for any app that didn't come from the Play Store. Tap More details, then Install anyway. You only see this once.

Optional: SMS matching

AliTrack can show the delivery messages your couriers send, attached to the right parcel. Android won't let an app installed outside the Play Store read messages, so that part lives in a separate 59 KB add-on. Everything else works without it.

Don't download it here. Install AliTrack first, then open Settings → SMS matching → Install SMS plugin and it will fetch and install the add-on for you. That route avoids the warnings you'd get downloading it in a browser.

One extra step Android requires After the add-on installs, open AliTrack SMS Plugin and tap Grant SMS access. Android will refuse the first time — that's normal for apps outside the Play Store. The add-on then shows you the fix: App info → ⋮ → Allow restricted settings → Permissions → SMS → Allow. Once only.

If the in-app install fails, you can download the add-on directly — expect Android to push back harder on that route.
